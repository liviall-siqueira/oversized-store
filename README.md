# Great Oversized

Projeto desenvolvido para a disciplina de Desenvolvimento Web.

## Sobre o projeto

A Great Oversized é uma landing page de uma loja fictícia de camisetas oversized. O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com foco em responsividade, navegação entre páginas e integração com a API ViaCEP para preenchimento automático de endereço.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API ViaCEP
- Git e GitHub

## Funcionalidades

- Página inicial responsiva
- Catálogo de produtos utilizando CSS Grid Layout
- Navegação entre páginas com JavaScript
- Formulário de cadastro
- Preenchimento automático de endereço com a API ViaCEP
- Layout responsivo para dispositivos móveis
